Three Ways to Run

Use the same host and tools whether you deploy to Dataverse or test straight from a local/GitHub Pages host.

☁️

1. Inside Power Platform

Upload independent dvot_host.html plus either individual tool files or a single bundled tool pack (dvot_bundle_*.html) as HTML Web Resources. The host auto-discovers and unpacks them using your active Dynamics session.

🔌

2. External / GitHub Pages + Proxy

Click Open Host → right from this page. Outside *.dynamics.com, the host asks only for your local proxy URL (default http://127.0.0.1:8787) backed by PowerShell, C# .NET, or Node.js.

🛡️

3. Local Auth Security

Environment URL and OAuth Bearer token acquisition (pac auth token or az) stay strictly inside your local dev-server/ process memory — never saved in browser storage.

.\dev-server\dev-server.ps1 -Env https://yourorg.crm.dynamics.com
