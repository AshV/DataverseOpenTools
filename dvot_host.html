        Running outside Power Platform. Point the host to your running local proxy server.
      

      

        
        
        

          Dataverse Environment URL and Bearer token stay strictly inside your local proxy:

          C# (.NET): dotnet run --project dev-server -- --env https://yourorg.crm.dynamics.com
